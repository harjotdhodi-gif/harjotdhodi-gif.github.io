# Public GitHub Projects

These repositories provide public, inspectable evidence of current documentation-engineering and AI-assisted documentation work.

## AI Docs-as-Code with MkDocs

**Repository:** [AI-Docs-as-Code-MKDocs](https://github.com/harjotdhodi-gif/AI-Docs-as-Code-MKDocs)  
**Published site:** [harjotdhodi-gif.github.io/AI-Docs-as-Code-MKDocs](https://harjotdhodi-gif.github.io/AI-Docs-as-Code-MKDocs/)

A governed documentation workflow built around Markdown, MkDocs Material, GitHub Actions, Vale, AI-assisted review, and human approval.

**Implemented workflow highlights**

- Markdown source documentation in GitHub
- MkDocs Material static-site publishing
- GitHub Actions CI/CD
- Vale deterministic style and terminology checks
- AI-assisted documentation review
- Human approval controls
- HTML publication through GitHub Pages
- Automated PDF and DOCX outputs

**Why it matters:** Demonstrates documentation as a versioned engineering workflow rather than a standalone authoring activity.

## What These Projects Demonstrate

Together, these repositories show the shift from conventional document authoring toward **documentation engineering**:

1. Content is maintained as source-controlled knowledge.
2. Changes are reviewable and traceable.
3. Automated checks can detect deterministic issues.
4. AI can assist with contextual review without becoming the final approver.
5. Human review remains part of the publishing gate.
6. Approved source content can generate multiple delivery formats.
