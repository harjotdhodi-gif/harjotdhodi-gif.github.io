# RCA Documentation Governance

![RCA documentation governance flow](/img/portfolio/governance-flow.svg)

**Organization:** Recovery Centers of America  
**Role:** Documentation Specialist (Contract)  
**Period:** May 2023 - Jul 2025  
**Domain:** Healthcare IT

## Context

I partnered with IT Operations, Mission Center, Business Intelligence, Enterprise Applications, Telephony, and PMO teams supporting US East Coast operations.

## Challenge

The documentation environment required consistent ownership, naming, version control, approvals, recurring review, and better visibility across multiple IT functions while maintaining HIPAA-aligned content controls.

## What I established

- Centralized documentation ownership
- Naming and numbering conventions
- Version-control expectations
- Approval workflows
- Recurring review schedules
- Documentation audits
- A Smartsheet dashboard exposing document status, owners, review cycles, and delivery metrics

## Deliverables

Policies, procedures, runbooks, FAQs, workflow diagrams, user guides, and training materials covering identity and access management, endpoint deployment and patching, email security, VPN, telephony, backup, virtualization, and SSL certificate reviews.

## Value demonstrated

The work shows documentation not only as authored content, but as a **governed operational system** with visible ownership, review discipline, and audit readiness.
