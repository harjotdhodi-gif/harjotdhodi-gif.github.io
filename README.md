# Harjot Singh Dhodi — Professional Portfolio

GitHub Pages portfolio for **Harjot Singh Dhodi — Principal Technical Writer, Documentation Manager, and Documentation Engineer**.

## Portfolio focus

- Enterprise technical writing
- Documentation strategy and governance
- Docs-as-Code and documentation engineering
- Knowledge bases and online help
- Release documentation
- Healthcare and life-sciences documentation
- eLearning and localization
- AI-assisted and RAG-ready documentation workflows

## Technology

- Docusaurus 3.10.2
- React 19
- Markdown / MDX
- GitHub Actions
- GitHub Pages

## Local preview

```bash
npm install
npm start
```

## Production build

```bash
npm run build
npm run serve
```

## Deployment

Pushes to `main` run `.github/workflows/deploy-pages.yml`, build the Docusaurus site, and deploy the generated `build/` directory to GitHub Pages.
